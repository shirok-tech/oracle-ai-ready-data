# oracle-ai-ready-data v0.4.0 — Annotation / Domain Advisory

リリース日：2026-09-29。実DB最終再検証日：2026-09-23。

Oracle DatabaseのAnnotationとDomain由来の意味情報を、任意のAdvisoryとして収集・可視化できるようにしました。既存のAI Readyスコア、重み、COMMENT必須ゲートは維持しています。

## 追加機能

- `generate_semantics_collector.py`で読み取り専用の補助収集SQLを生成。
- `--semantics-input`で補助JSONを既存Scorerへ追加。
- 表Annotation、列Annotation coverage、直接登録／Domain継承／由来不明、列のDomain関連付けを表示。
- 収集成功・未収集・非対応確認済み・権限不足確認済み・原因未確定・エラーを区別。
- 日本語／英語のMarkdownと自己完結HTMLにAdvisoryを追加。
- 第3回の最小比較用SQL生成器と、辞書・プロンプト・保存SQL実行・別試行RUNSQLを区別する証跡テンプレートを追加。

## 修正

- 通常CollectorはSPOOL開始前に`SET ECHO OFF`を設定し、呼び出し元のECHO ONを引き継いだ出力混入を防止。
- Scorerはecho混入や必須セクション・CSV構造の不備を採点前に拒否。不正入力では終了コード1となり、レポート等を生成しません。
- セマンティクスCollectorから`SET SQLCASE MIXED`を削除し、SQLcl 25.4でのObsolete警告を解消。

## 利用方法

```bash
python3 scripts/generate_semantics_collector.py \
  --owner BAD_AI_READY --table-like 'AIRD_T0%' \
  --output collect_semantics.sql \
  --spool-file semantics_r01.json
```

生成SQLを確認し、新しい保存先で接続済みSQLclから実行します。通常Collectorのscanも同じ対象範囲で収集します。

```bash
python3 scripts/score_oracle_ai_ready_scan.py \
  oracle_ai_ready_scan_BAD_AI_READY_scan.out \
  --semantics-input semantics_r01.json \
  --profile scan --language ja \
  --output report.md --html-output report.html
```

`--semantics-input`を省略した既存CLIも利用できます。意味情報は未収集・N/Aとして表示されます。

以前生成したセマンティクスSQLには古い設定が残るため、アップデート後は新しい出力先へ再生成してください。過去のscanは加工せずに保持し、入力エラーになったものは新しい保存先で再収集します。

- ローカル：2026-09-29にリリース対象の作業ツリーで再確認。Python 3.14.3で69テスト成功、compileall・git diffチェック成功。
- 実DB：Oracle AI Database 26ai 23.26.3.3.0、SQLcl 25.4で2026-09-23に最終再検証。
- ECHO ONから正常scanを取得し、2表・6列を認識。
- 意味情報JSONは修正前と収集日時以外の内容が一致。
- 直接Annotation 1列、Domain継承1列、Domain関連1列、列coverage 2/6＝33.33%を確認。

- 保存済み不正scanは終了コード1で拒否。MD／HTML／改善SQLは未生成。

- 日本語・英語HTMLの数値、日本語Annotation、Domain由来表示、読みやすさを利用者が目視確認済み。

## 互換性と範囲

- Annotation／Domainは加点要素ではなく、COMMENTやPK/FKの代替でもありません。
- coverageは通常scanと収集範囲が重なるdistinct列を母数にします。未収集・失敗・対象0列はN/Aです。
- 辞書情報は接続Userから見える範囲です。View経由の継承、高度なDomain機能、汎用NL2SQL自動採点は今回の範囲外です。
- 正常な0表・0列については従来のスコア／ゲート計算を維持しています。0.97／passと表示されても、対象0件をAI Ready認定の根拠にはしません。
- Python 3.10以上・標準ライブラリのみの対応方針を維持していますが、今回報告されたローカル実行環境は3.14.3です。
- 実DB検証は上記の環境に対するものです。全DBバージョン・全権限構成での検証を意味しません。

最小のSelect AI実測ではAnnotation Onの正答を確認していますが、その正答回数は限定したデータ・質問・モデルによる過去実測です。レポートのcoverageや本リリースが、一般的なNL2SQL精度を保証するものではありません。
